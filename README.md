# 🎓 نظام تتبع المحاضرات والواجبات الجامعية - University Lecture & Assignment Tracker

مشروع ويب متكامل مصمم لتسهيل العملية التعليمية وتنسيقها بين الأساتذة والطلاب. يتيح النظام لكل أستاذ إدارة محاضراته وواجباته الخاصة بكل مادة، ويسمح للطلاب بمتابعة الجدول الدراسي وتسليم الواجبات والاطلاع على التحديثات الخاصة بموادهم.

---

## 🚀 المميزات الرئيسية لجميع الأطراف

### 👨‍🏫 لوحة تحكم الأستاذ (Professor Dashboard)
- إدارة المواد: إضافة وتعديل المواد الدراسية المسندة للأستاذ.
- تتبع المحاضرات: تسجيل مواضيع المحاضرات، تواريخها، ورفع الملفات المرفقة بها.
- إدارة الواجبات: إنشاء واجبات جديدة لكل مادة، تحديد المواعيد النهائية (Deadlines)، واستلام إجابات الطلاب وتقييمها.

### 🧑‍🎓 لوحة تحكم الطالب (Student Dashboard)
- جدول المحاضرات: عرض جدول المحاضرات الخاص بالمواد المسجل بها.
- تتبع الواجبات: متابعة الواجبات المطلوبة، تاريخ التسليم النهائي، وحالة التسليم (تم التسليم / قيد الانتظار).
- تسليم الواجبات: إمكانية رفع إجابات الواجبات مباشرة من خلال النظام.

### 🛡️ لوحة تحكم المسؤول (Admin Dashboard)
- إدارة المستخدمين: إنشاء وحذف حسابات الأساتذة والطلاب.
- إدارة المواد الدراسية: ربط المواد بالأساتذة والطلاب المناسبين.

---

## 🛠️ التقنيات المستخدمة
- لغة البرمجة (Backend): PHP
- قاعدة البيانات (Database): MySQL
- الواجهة الأمامية (Frontend): HTML / CSS
---

## 💻 طريقة تشغيل المشروع محلياً

1. تأكد من تحميل وتثبيت برنامج XAMPP أو WampServer على جهازك.
2. قم بنسخ مجلد المشروع بالكامل وضعه داخل مجلد htdocs في الـ XAMPP (أو مجلد www في الـ WampServer).
3. افتح المتصفح وادخل إلى صفحة localhost/phpmyadmin.
4. أنشئ قاعدة بيانات جديدة باسم itcs3.
5. قم بعمل استيراد (Import) لملف قاعدة البيانات المرفق مع المشروع itcs3.sql.
6. افتح المشروع في المتصفح عبر الرابط: localhost/university_admin.
